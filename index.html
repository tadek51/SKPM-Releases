System Kalkulacji Produkcji Mechanicznej

Praktyczne narzędzie do kalkulacji procesów produkcyjnych

O programie

SKPM wspomaga przygotowanie kalkulacji technologicznych, analizę czasów operacji oraz zestawianie danych produkcyjnych.

Funkcjonalności

  • Cięcie i nesting materiałów
  • Toczenie i frezowanie
  • Wiercenie i gwintowanie
  • Spawanie i montaż
  • Zestawienie czasu i masy zlecenia
  • Eksport do Excela i zapis JSON

Pobierz SKPM

Wersja testowa 1.0.0 — Windows 10/11.

Pobierz instalator

Po pobraniu rozpakuj ZIP i uruchom setup.exe.

Uwaga: instalator nie jest jeszcze podpisany cyfrowo. Windows może wyświetlić ostrzeżenie o nieznanym wydawcy.
